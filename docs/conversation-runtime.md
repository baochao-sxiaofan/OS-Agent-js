# 会话、批量处理与自主发言

## 目标与边界

- Agent 是用户创建的长期身份；用户私聊、Agent 私聊、群聊是独立会话。
- 消息只存入目标会话。只有显式发送消息动作产生聊天记录，内部运行结束与总结不产生气泡。
- 模型可合并处理一批来信后发言一次，也可不发言。处理进度与发送行为分别持久化。
- 群聊支持点名优先和普通消息聚合；模型根据职责、指向与已有回答决定是否贡献。
- 同一 Agent 仍只持有一个调度凭据；会话状态不引入父子 Agent。
- 先覆盖同一宿主管理的 Agent 及当前用户，Agent 间仍要求同一工作区。
  多用户跨宿主成员管理不在这次实现中。

## 实施设计

### 持久会话模块

在新 Runtime 内增加独立的会话存储和聚合模块，核心不依赖桌面：

- Conversation：稳定标识、类型、标题、用户/Agent 成员、群参与策略、创建时间。
- Message：稳定标识、会话、递增序号、可信发送者、正文、可选回复引用与点名成员。
- Mailbox：每个 Agent/会话的已处理位置、首次到达时间、聚合截止时间。
- Delivery batch：一个 Agent、一个会话、固定消息上界与消息集合，持久记录排队/已接收状态。
- 发件幂等记录与消息同事务提交；发件人不接收自己的唤醒事件。
- 共享自动发言预算按用户推动的交流阶段累计，不能因 Agent 发出新消息重置。

成员、发件人、回复引用、点名范围均在可信宿主校验。读取自己的对话与管理查看
Agent 会话使用不同接口；管理查看不增加成员、不发送已读回执、不触发模型。

### 聚合和调度

- 默认短窗口聚合连续消息，并有固定最大等待上限；群中未点名的普通消息可使用较低处理频率。
- 私聊、点名和指向自己发言的回复优先；群支持参与讨论或仅被点名处理。
- 聚合模块将固定的消息批次引用交给现有 scheduler.notify，不修改已封存的调度批次。
- 同一 Agent 只有当前会话取得执行权，其他会话保持持久排队。
- 当前会话完成、静默结束或总结结束后，确认实际处理的上界，再选择下一个会话。
- 运行期间新到达的消息不被本次确认消费；崩溃后重放同一批次，不重复发件。
- 查询展示聚合等待、处理中、已处理等事实；沉默不产生虚假的回复或“对方正在输入”承诺。

### 上下文和模型动作

- 复用 Context Manager，为每个 Agent/会话保存独立的上下文检查点。
  一个 ACB 的只读上下文端口指向当前会话，不增加并发执行身份。
- 长期职责与权限沿用 Agent 配置，其他会话的原文与摘要不自动混入当前请求。
- 请求提供当前会话、成员、固定消息批次、自己的发言历史，以及允许发送的会话目标。
- 增加明确的 message.send 动作，支持合并回复及可选结束本轮。
  发送结果作为自己的上下文事件保存；只有该动作写聊天消息。
- 增加无需模型总结的静默结束动作；仅允许根层无未完成任务、无在途操作时结束。
  普通业务任务仍使用已有独立总结，容量达到阈值时仍触发压缩。
- 原 agent_output 只作为内部交付保留兼容，不再自动公开到用户私聊；
  不向新请求暴露强制公开回复的工具或提示。
- 请求/答复关联辅助理解，不要求每条来信必须回复，也不制造回复的回复。
- 工具和历史引用使用稳定短编号，宿主严格还原原来源；消息回复、读取与备注来源
  同样还原后校验，其他成员或未投递资料不能借编号越权读取。
- SDK 的 `provideFeedback(agentId, ownerId, content, idempotencyKey)` 可向当前执行层
  投递宿主现场纠错，独立保存幂等记录并复用调度唤醒。它不发送聊天、不清邮箱游标、
  不扩权、不替模型修改任务状态；用于正在执行时发现的故障或事实错误。

### 桌面和 HTTP

- 默认“我的对话”仅返回当前用户参加的正常会话。
- Agent 入口列出长期联系人，选择后管理查看该 Agent 的会话，非本人参与的会话只读。
- 支持创建群、选择现有 Agent、群参与策略、选择点名对象、查看成员和消息发送者。
- 未读持久保存，草稿在当前窗口按会话保存；切换视角不能污染自己的未读或消息路由。
- 用户私聊顶部保留 Agent 管理操作；群状态展示对应成员的真实处理状态。
- HTTP 同步提供会话列表、创建、消息与管理查看接口，并严格校验宿主和成员。

### 历史兼容

- 保留全部原始身份、数据库和执行记录。
- 旧混合历史中不能确定目标的输出不推测迁移为用户回复，作为只读历史归档查看。
- 已在执行的工具和总结恢复必须沿用原现场，不以会话迁移重新执行副作用。
- 原 submit/messages 控制面入口保留为用户与指定 Agent 私聊的兼容入口；
  旧协作动作如需恢复，只能映射到明确的 Agent 私聊，不能再次汇入用户私聊。
